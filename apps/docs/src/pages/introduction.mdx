# QuickadUI

A complete frontend ecosystem for building React applications — components,
layouts, theming, hooks, icons, animation, and a CLI, all under one
`@quickadui/*` namespace. This site documents every visual package plus
`theme` — `utils`/`hooks` (non-visual utilities) and `config`/`cli`
(tooling) are out of scope here, documented elsewhere.

<Badge variant="soft">Hand-written pages</Badge>

## What's here, and what isn't yet

`apps/docs` is a real, running Vite + MDX site with navigation, a layout,
and one hand-written page per covered package: `tokens`, `theme`,
`primitives`, `core`, `layout`, `forms`, `data`, `overlays`, `shell`,
`charts`, `animation`, and `icons`. Every example on these pages renders
the real, built `@quickadui/*` packages — this site dogfoods itself the
same way `apps/playground` does.

Two things are deliberately **not** built yet, and every prop table below
is hand-written because of it:

- **Generated prop tables.** Parsing real TypeScript source into prop
  tables automatically is planned (see `ARCHITECTURE.md`, §10), but this
  pass proves out the site's structure first with hand-written tables.
- **Live Sandpack playgrounds.** Examples here render live but aren't
  editable in the browser yet.

Later rounds also add versioning per published major and a guides layer
("Migrating from Chakra/MUI/Mantine"). None of that is in this build.

## Install

```bash
pnpm add @quickadui/core @quickadui/tokens @quickadui/theme
```

Wrap your app in `ThemeProvider` (from `@quickadui/theme`) and import its
generated CSS once, alongside Tailwind v4 itself — see this site's own
`src/main.tsx` and `src/index.css` for a working example of both.
