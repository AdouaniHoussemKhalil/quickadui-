# QuickadUI

QuickadUI is a complete frontend ecosystem for building React admin and
dashboard apps: styled components (buttons, forms, tables, charts...),
page layout, light/dark theming with an accent-color picker, icons,
animation, and a CLI that can scaffold a whole app for you. Everything
lives under a single `@quickadui/*` namespace and is built on
[Radix UI](https://www.radix-ui.com) primitives, so components come with
keyboard navigation, focus management, and ARIA wiring out of the box.

Every example on this site renders the real, built `@quickadui/*`
packages — nothing here is a mockup.

## Where to start

- **Starting a new project?** [Create your first project](#create-your-first-project)
  walks through the `quickadui` CLI step by step: scaffolding, the config
  file, the most common setup scenarios, and a CSS gotcha almost everyone
  hits once.
- **Adding QuickadUI to an existing project?** Install the packages below,
  wrap your app in `ThemeProvider`, and start importing components from
  whichever package covers what you're building.

## Install

```bash
pnpm add @quickadui/core @quickadui/tokens @quickadui/theme
```

Wrap your app in `ThemeProvider` (from `@quickadui/theme`) and import its
generated CSS once, alongside Tailwind v4 itself — see this site's own
`src/main.tsx` and `src/index.css` for a working example of both.
