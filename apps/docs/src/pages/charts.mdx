# Charts

`@quickadui/charts` covers dashboard-style charts — grouped bars, lines,
donuts, inline sparklines, and metric tiles — each hoverable/focusable with
a shared tooltip convention, and a legend whenever there's more than one
series. Requires its own stylesheet import alongside `@quickadui/theme`'s
generated CSS (this site's own `src/index.css` does this):

```css
@import "@quickadui/charts/chart-tokens.css";
```

live inside a `StatCard` or a narrow `Widget`, single series only.

## StatCard

One dashboard metric — a label, a large value, an optional colored trend
badge, and an optional embedded visual (typically a `Sparkline`). Meant to
be dropped inside a `@quickadui/shell` `Widget` as its body, or used
standalone.

<Example
  code={`<StatCard label="Revenue" value="$18.2K" trend={{ direction: "up", label: "+12%" }}>
  <Sparkline data={[4, 6, 5, 8, 7, 9, 12, 10, 14, 13, 16, 18]} />
</StatCard>`}
>
  <StatCard label="Revenue" value="$18.2K" trend={{ direction: "up", label: "+12%" }}>
    <Sparkline data={sparklineData} />
  </StatCard>
</Example>

## Categorical palette

Multi-series charts pull colors from a fixed, CVD-safe (color-vision-
deficiency-safe) set of 8 — always assigned in the same order, never
cycled or reordered independently. A single-series chart (`Sparkline`, or a
`BarChart`/`LineChart` with one series) uses QuickadUI's own brand accent
instead — a lone series needs no legend and no separation guarantee, so
it's free to match the rest of the design system.
