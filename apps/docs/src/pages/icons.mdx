# Icons

`@quickadui/icons` re-exports a curated set of [Lucide](https://lucide.dev)
icons under stable QuickadUI names, plus a couple of QuickadUI-original
glyphs — a consumer never imports `lucide-react` directly. This list grows
incrementally as components need new icons; it isn't meant to cover all of
Lucide, just what QuickadUI's own components use plus a handful of
generically useful ones.

## Usage

Every icon is a plain SVG component — import the one you need by name and
size it like any other element:

<Example
  code={`<SearchIcon size={20} />
<UserIcon size={20} color="var(--color-accent-9)" />
<TrashIcon size={16} strokeWidth={1.5} />`}
>
  <div className="flex items-center gap-4">
    <SearchIcon size={20} />
    <UserIcon size={20} color="var(--color-accent-9)" />
    <TrashIcon size={16} strokeWidth={1.5} />
  </div>
</Example>

Every icon here is purely decorative unless it's the only content of an
interactive element (a close button, say) — pair it with `aria-hidden` when
adjacent visible text already conveys the meaning, or with an accessible
label (`aria-label`, or a visually-hidden `<span>`) when it isn't.
