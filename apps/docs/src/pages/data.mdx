# Data

`@quickadui/data` covers the components a real screen full of records
tends to need: tables, pagination, multi-step flows, timelines, tree
views, and a draggable sortable list.

## SortableList

<Example
  code={`function SortableListDemo() {
  const [items, setItems] = useState(["a", "b", "c"]);
  return (
    <SortableList items={items} onReorder={setItems}>
      <SortableItem id="a">Design review</SortableItem>
      <SortableItem id="b">Ship the changelog</SortableItem>
      <SortableItem id="c">Reply to support tickets</SortableItem>
    </SortableList>
  );
}`}
>
  <SortableListDemo />
</Example>

Draggable with the mouse/pointer and the keyboard (via `@dnd-kit`) — the
same machinery `@quickadui/shell`'s `WidgetGrid` uses for a 2D grid of
dashboard widgets, here specialized for a single-column list: a
reorderable settings list, a priority-ranked list, a Kanban column, ...
Drag a row below to reorder it; the new order is just local `useState` in
this demo. Omitting `onReorder` renders a plain, non-draggable list
instead, with no `DndContext` mounted at all.

<PropsTable
  rows={[
    { name: "items", type: "string[]", description: "Ordered item ids — must match each SortableItem child's id, in the same order they're rendered." },
    { name: "onReorder", type: "(items: string[]) => void", description: "Called with the reordered id array once a drag completes. Omit for a plain, non-draggable list." },
  ]}
/>

<PropsTable
  rows={[
    { name: "id", type: "string", description: "SortableItem only, required — must match this item's entry in its SortableList's items array." },
    { name: "disableDrag", type: "boolean", default: "false", description: "SortableItem only — hides the drag handle and disables dragging for just this item." },
  ]}
/>
