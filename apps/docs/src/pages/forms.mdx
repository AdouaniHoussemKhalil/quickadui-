# Forms

`@quickadui/forms` covers everyday form controls, plus a `Form`/`FormField`
layer (re-exporting `react-hook-form`, with a `zodResolver` re-export for
`zod` schemas) for wiring them up with validation. The examples below show
the controls standalone; a full `Form` + `zod` walkthrough is planned for
a later pass of this page.

  <Input
    readOnly
    value="npm install @quickadui/core"
    endIcon={<CopyButton value="npm install @quickadui/core" size="sm" variant="ghost" />}
  />
</Example>

`startIcon`/`endIcon` accept any `ReactNode`, not just an icon component — the
last example above embeds a whole `CopyButton`. The slot isn't
click-through: a plain decorative icon just sits there same as always, but
an interactive child (a button) stays fully clickable, unlike a naive
`pointer-events-none` overlay would allow. `PasswordInput`'s reveal toggle
(below) is built the same way — it's just `Input`'s own `endIcon` slot with
a button inside.

## Password input

<Example
  code={`<PasswordInput placeholder="Enter a password" showStrength />`}
>
  <PasswordInput placeholder="Enter a password" showStrength className="w-full max-w-sm" />
</Example>

A plain `Input` with a trailing eye/eye-off toggle to reveal the value,
plus an optional live strength meter (`showStrength`) below it — a
segmented bar plus a per-rule checklist (length, uppercase, lowercase,
number, symbol) that updates on every keystroke. Built on a hand-rolled
rule checker (`getPasswordStrength`, re-exported from this package)
rather than a third-party scoring library — no extra dependency to
install, and every rule maps to something the user can see and fix while
typing, unlike an opaque entropy estimate.

<PropsTable
  rows={[
    { name: "showStrength", type: "boolean", default: "false", description: "Renders a PasswordStrengthMeter below the field, reading this same input's live value." },
    { name: "strengthRules", type: "PasswordRule[]", default: "defaultPasswordRules", description: "Custom rule set forwarded to the strength meter — a different minimum length, requiring a symbol, etc." },
  ]}
/>

`PasswordStrengthMeter` (the bar + checklist alone) and
`getPasswordStrength` (the pure scoring function both are built on) are
also exported separately — render the meter standalone next to a
"confirm password" field, or call `getPasswordStrength` directly for
server-side validation.

## Form + validation

`Form` is `react-hook-form`'s own `FormProvider` under QuickadUI's name;
`FormField`/`FormItem`/`FormLabel`/`FormControl`/`FormDescription`/
`FormMessage` wire up ids, `aria-*` attributes, and error display for you,
the same pattern shadcn/ui's `Form` uses. Combine with `useForm` +
`zodResolver` for schema validation. A worked example belongs on this page
in a later pass, once this MVP's structure is proven out.
