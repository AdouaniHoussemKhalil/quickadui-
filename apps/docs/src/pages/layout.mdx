# Layout

`@quickadui/layout` covers arranging things on a page — centering and
capping width (`Container`), vertical rhythm (`Section`), and arranging
children (`Flex`, `Stack`, `Grid`). None of these render any visual chrome
of their own beyond what their variant props ask for.

## Container

Centers content and caps its width — the outermost wrapper for a page's
content.

<Example
  code={`<Container maxWidth="sm">
  <div>max-w-3xl, centered</div>
</Container>`}
>
  <Container maxWidth="sm" className="border border-dashed border-neutral-6">
    <div className="rounded-md bg-accent-3 p-4 text-center text-sm text-accent-11">
      max-w-3xl, centered
    </div>
  </Container>
</Example>

  ]}
/>

## Flex

The general-purpose flexbox primitive `Stack` and `Grid` build on top of.

<Example
  code={`<Flex gap="sm">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</Flex>`}
>
  <Flex gap="sm">
    <div className="rounded-md bg-accent-3 p-3 text-sm text-accent-11">1</div>
    <div className="rounded-md bg-accent-3 p-3 text-sm text-accent-11">2</div>
    <div className="rounded-md bg-accent-3 p-3 text-sm text-accent-11">3</div>
  </Flex>
</Example>

## Stack

Sugar over `Flex`, defaulting to a vertical stack (`direction="column"`,
`gap="md"`) instead of `Flex`'s horizontal, gap-less defaults — the common
case of "these things, spaced out, one under the other."

<Example
  code={`<Stack gap="sm">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</Stack>`}
>
  <Stack gap="sm" className="max-w-xs">
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">1</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">2</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">3</div>
  </Stack>
</Example>

<PropsTable
  rows={[
    { name: "direction", type: '"row" | "column"', default: '"column"', description: "flex-direction — a narrower set than Flex's, since Stack is for the simple vertical/horizontal case." },
    { name: "align", type: '"start" | "center" | "end" | "stretch"', default: '"stretch"', description: "align-items." },
    { name: "gap", type: '"none" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl"', default: '"md"', description: "Same gap scale as Flex/Grid." },
  ]}

## Grid

`columns` is a fixed set of common column counts — CSS utility classes have
to exist ahead of time for Tailwind to generate them, so an arbitrary count
outside this set needs `className` directly (e.g. `grid-cols-[7]`) instead.

<Example
  code={`<Grid columns="3" gap="sm">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
  <div>6</div>
</Grid>`}
>
  <Grid columns="3" gap="sm">
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">1</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">2</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">3</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">4</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">5</div>
    <div className="rounded-md bg-accent-3 p-3 text-center text-sm text-accent-11">6</div>
  </Grid>
</Example>

## Section

A `<section>` with vertical rhythm baked in — the unit a page is usually
built out of (hero, features, footer, ...). Renders a real `<section>`, not
a `<div>`; wrap it in `Container` for horizontal centering, they're
independent concerns.

<Example
  code={`<Section spacing="sm">
  <div>py-8 of vertical rhythm</div>
</Section>`}
>
  <Section spacing="sm" className="border-y border-dashed border-neutral-6">
    <div className="text-center text-sm text-neutral-11">py-8 of vertical rhythm</div>
  </Section>
</Example>

<PropsTable
  rows={[
    { name: "spacing", type: '"sm" | "md" | "lg" | "xl"', default: '"md"', description: "Vertical padding." },
  ]}
/>
