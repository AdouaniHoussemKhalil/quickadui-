# Shell

`@quickadui/shell` is the full admin/dashboard app frame: `DashboardLayout`
composes a `Navbar`, a collapsible `Sidebar`, a scrollable content column,
and an optional `Footer`; `Widget`/`WidgetGrid` lay out draggable dashboard
cards inside that content column.

## DashboardLayout

`DashboardLayout` sets `h-screen` on its own root — it's meant to be the
outermost layout element on a real page. The embedded demo below overrides
that with a fixed height so it fits on this page instead; a real
integration renders it unconstrained, at the top of the app tree.

<Example>

## Widget & WidgetGrid

A responsive grid of `Widget` cards, drag-and-drop sortable (pointer and
keyboard, via `@dnd-kit`) whenever `onReorder` is given — drag a card below
to reorder it, the new order is just local `useState` in this demo.
Omitting `onReorder` renders a plain grid instead, with no `DndContext`
mounted at all.
