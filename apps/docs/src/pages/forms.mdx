# Forms

`@quickadui/forms` covers everyday form controls, plus a `Form`/`FormField`
layer (re-exporting `react-hook-form`, with a `zodResolver` re-export for
`zod` schemas) for wiring them up with validation. The examples below show
the controls standalone; a full `Form` + `zod` walkthrough is planned for
a later pass of this page.

## Form + validation

`Form` is `react-hook-form`'s own `FormProvider` under QuickadUI's name;
`FormField`/`FormItem`/`FormLabel`/`FormControl`/`FormDescription`/
`FormMessage` wire up ids, `aria-*` attributes, and error display for you,
the same pattern shadcn/ui's `Form` uses. Combine with `useForm` +
`zodResolver` for schema validation. A worked example belongs on this page
in a later pass, once this MVP's structure is proven out.
